# NOVA — Market Intelligence

A dark, premium market-intelligence themed portfolio concept for a full-stack developer.

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Notes
- Market figures and metrics are intentionally illustrative.
- AI visual placeholders are included in the first pass so the layout can be tested before generated imagery is added.
- The implementation follows the supplied design system: restrained typography, controlled container widths, subtle reveal animations, no blur/glass effects, semantic interactive elements, native smooth scroll, responsive layouts, and reduced-motion support.
